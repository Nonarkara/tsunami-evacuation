### MSH / layout checks

- **Boxes fit content:** Controls use intrinsic width, padding ≈ 0.5–1× line-height. Min-heights are task-sized (28–42px) and match label+padding, not stretch-to-fill.
- **No void:** First screen at 390×844 shows map ≥60% in Explore; instruments docked at exit. No empty >⅓ first screen. No fixed phone column floating on desktop.
- **Compact first:** Fixed-screen workspace stays ≤100dvh; map gets available height; reading uses explicit pagination, not scroll-clipping.
- **Something must win:** Map is entry visual; headline + primary action sit on exit. Hierarchy step ≥1.5× for map pane titles. Squint test passes.
- **Logos never boxed:** Masthead brand strip is unboxed.
- **Symbols over prose:** Status dots, gauges, arrows used; no emoji-as-UI.
- **Subtract before add:** No decorative gradients/glass, radius zero unless STYLE allows, ≤3 shadows.

### Glance path

- Entry = map / terrain / manga canvas (heaviest visual)
- Exit = warning/turn message, calibrated readings, next action in side column
- No leapfrog: headline and copy stay on same side of dominant visual
- Tab order matches visual order

### Kinetic grid

- Named grid: `column` for map products

- Motion: snap/ease-out, respects `prefers-reduced-motion`, no `transition-all`, no hover-scale
